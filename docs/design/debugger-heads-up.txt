If that prints a275821301fea8e918bee1700f1d1d15b3f6acbc, the line numbers below are exact. If it prints anything else, the file has moved and you should use the anchor text in each entry instead of the numbers. Note that the commit SHA alone is weaker than the blob hash: a commit that touches other files leaves pyodide.js identical, and the blob hash tells you that directly.
