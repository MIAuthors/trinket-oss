What's New

{{ config.app.siteName }} has had a lot of work done since it launched. Here are the changes you're most likely to notice.

Writing and running code

  • Python is real Python. Your code runs actual CPython in the browser, so libraries like numpy and matplotlib work the way they do on a desktop — and there's now a single Python option instead of several confusing variants.
  • input() works. Programs that ask the user for input used to fail immediately. They don't any more.
    • {% if config.features.variableExplorer %}
  • Variables tab. See every variable your program creates, and click to expand lists, dictionaries and objects.
    • {% endif %} {% if config.features.stepDebugger %}
  • Step through your code. Run your program, then walk through it one line at a time — forwards and backwards. Watch variables change, drag the slider to jump around, and click in the left margin to set a breakpoint and skip straight to the interesting part.
    • {% endif %}
  • Better plots and graphics. matplotlib labels no longer get cut off, and the VPython canvas can be resized properly.
  • iPad friendly. The dividers between your code and the output can be dragged with a finger.

For instructors

  • Publishing works. The Publish dialog previously did nothing at all when clicked. You can now publish a trinket to its own page and share the link.
  • A My Courses page, and course deletion you can actually find.
  • Manage trinkets in bulk — select several at once to move or delete them, with filters and date ranges to find what you need.
  • Download student work, including your feedback, as a single export.
  • Easier rosters. Students who already have accounts are enrolled when they log in, and adding a large class at once works reliably.
  • Course pages behave. Image uploads work, the markdown editor highlights properly, and large course archives import without hitting a size limit.

Coming from trinket.io

  • Old trinket.io links point at the matching trinket here.
  • Imported course pages now show this site's trinkets, instead of quietly loading trinket.io's editor.
  • Imported Python trinkets open correctly, including older ones that used to show "this trinket type is not available".

Fixes you'll simply stop noticing

  • A whole classroom logging in from one network no longer gets locked out.
  • Returning users aren't greeted with "your account has been created" every time.
  • Renaming a course or trinket no longer breaks its old link.
  • "Download All" only includes the trinkets you actually still have.
  • Saving a course page no longer gets stuck on a "modified in another window" error.
